# 标志设计

2026-10-20 定稿：**玉琮俯视（H2）**。外方内圆、四角分节、圆孔外立一圈口沿，取"天圆地方"；玉青配墨黑，和首页一致。

- 正式文件：`web/src/assets/brand/logo.svg`（网站图标）、`apple-touch-icon.png`（180×180，苹果主屏，无圆角，系统自己裁）；页面里用 `web/src/components/Logo.tsx`（同一图形内联绘制）。
- 设计过程：
  - `logo-drafts-1.png`：A–F，常规方向（枢纽、天枢星、浑仪、门枢、印章、L），用户评价"没啥新意"。
  - `logo-drafts-2.png`：G–N，从《灵枢》出处找（一针、玉琮、司南、北斗、灵气、朱印门枢、三环结、气门），用户选 H 玉琮。
  - `logo-drafts-3-cong.png`：H1–H6 玉琮变体，用户选 H2 俯视。
  - 同名 `.svg` 是各方案的源文件。
