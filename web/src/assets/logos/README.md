各家模型的单色 logo，来自 @lobehub/icons-static-svg 1.95.1（MIT 许可，见 LICENSE-lobehub-icons），只用于首页标识对应厂商。

- meta.svg：Muse（Meta 的模型）用 Meta 的标志。
- doubao.svg、hunyuan.svg：豆包 Seed（字节跳动）、腾讯混元 HY。
- gemini.svg：Google Gemini。
- `*-color.svg`：同一图标包的彩色版，用在管理端渠道列表里标识模板厂商。Kimi 的彩色版含白色部分，浅色主题下看不清，仍用单色版；MiMo 的图标是一行小字，渠道列表里改用小米标志 `xiaomi-color.svg`（来自 simple-icons 16.35.0，CC0，填了小米橙 #FF6900）。
